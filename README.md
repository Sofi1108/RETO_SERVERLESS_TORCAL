# Laboratorio de realidad virtual

Web hecha para el reto Serverless, con la temática de un laboratorio de realidad virtual.

- Diseñé la página principal con un estilo oscuro, moderno y llamativo.
- Añadí la cabecera, el menú, la presentación del laboratorio y varias secciones de experiencias.
- La página tiene un formulario para introducir nombre y email.
- Añadí validación para que no se pueda enviar el formulario vacío o con un email incorrecto.
- Conecté el formulario con la API de AWS API Gateway mediante una petición POST.
- Añadí mensajes para indicar si los datos se están enviando, si todo ha ido bien o si ha habido algún error.
- Hice la web responsive para que se vea bien en ordenador, tablet y móvil.
- Añadí un menú desplegable para la versión móvil.
- Preparé la política del bucket de S3 para permitir ver los archivos de la web.
